# AI 모의 면접 — 사용 가이드

---

## 앱 개요

음성으로 진행하는 AI 모의 면접 앱입니다.
AI 면접관이 질문을 말로 읽어주고, 사용자가 마이크로 답변하면 AI가 다음 질문으로 이어갑니다.
면접 내용은 세션 파일로 자동 저장되며, 이어하기가 가능합니다.

---

## 처음 시작하기 — 필수 설정 2가지

메인 화면에서 두 가지 항목이 ✅가 되어야 면접을 시작할 수 있습니다.

### 1. AI 연결 설정

우상단 **[⚙ 설정]** → **AI 연결 설정** 섹션

1. **Provider** 선택 (Gemini / OpenAI / Anthropic / Ollama / CLI)
2. **모델** 선택
3. **API Key** 입력 (Ollama·CLI는 생략)
4. **[연결 확인]** 클릭 → ✅ 표시 확인

> API Key 발급 방법은 `guide_api.md`, CLI 설치 방법은 `guide_cli.md`를 참고하세요.

### 2. 시스템 프롬프트

**[⚙ 설정]** → **면접 설정** 섹션의 시스템 프롬프트 입력란

- **비워두면** `default.txt`의 범용 면접관 프롬프트가 자동으로 사용됩니다. 별도 설정이 필요 없습니다.
- **직접 입력하면** 원하는 직군·회사·면접 스타일을 지정할 수 있습니다.

---

## 면접 시작하기

메인 화면에서 **[새 면접 시작하기]** 클릭

1. AI가 잠시 준비한 뒤 첫 질문을 음성으로 읽어줍니다.
2. 재생이 끝나면 **[🎤 녹음 시작]** 버튼이 활성화됩니다.
3. 버튼을 누르고 답변을 말하세요.
4. 답변이 끝나면 **[■ 답변 완료]** 버튼을 누르세요.
5. AI가 답변을 분석하고 다음 질문으로 이어집니다.

> **녹음은 자동으로 끊기지 않습니다.** 답변을 마친 후 직접 [■ 답변 완료]를 눌러야 합니다.

## 면접 화면 구성

| 영역 | 설명 |
|------|------|
| 상단 타이머 | 경과 시간 표시 |
| 대화 로그 | 면접관 질문과 내 답변이 순서대로 기록됨 |
| 상태 표시줄 | 현재 상태 (면접관 답변 중 / 녹음 중 / 처리 중 등) |
| **[🎤 녹음 시작]** | 답변 녹음 시작 |
| **[■ 답변 완료]** | 녹음 종료 및 AI 전송 |
| **[다른 주제로]** | 현재 질문 주제를 건너뛰고 새 주제로 전환 |
| **[■ 종료]** | 면접 종료 및 세션 저장 |

## 다른 주제로 버튼

답변 후 AI의 꼬리 질문이 너무 길어지거나, 다른 역량을 보여주고 싶을 때 사용합니다.

클릭하면 키워드 입력창이 열립니다.

- **키워드를 입력하면**: AI가 해당 방향의 주제로 질문을 유도합니다.  
  예) `리더십`, `트러블슈팅`, `프로젝트 아키텍처`
- **비워두고 확인하면**: AI가 자동으로 새로운 주제를 선택합니다.
- **취소하면**: 아무 동작도 하지 않습니다.

이 동작은 대화 로그에 기록되지 않습니다.

> [🎤 녹음 시작] 버튼이 활성화된 상태(LISTENING)에서만 사용 가능합니다.

## 세션 저장 및 이어하기

- 면접 내용은 **매 답변마다 자동 저장**됩니다. 갑자기 앱이 꺼져도 직전 답변까지 보존됩니다.
- 저장 위치: 앱 실행 폴더 하위 `sessions/` 폴더

### 이어하기

메인 화면 **[📋 세션 목록]** → 세션 선택 → **[▶ 이어하기]**

- AI가 이전 대화 내용을 전달받아 맥락을 이어갑니다.
- 이전 면접 경과 시간도 복원됩니다.
- Provider를 바꿔서 이어하기도 가능합니다 (예: Gemini API → Claude CLI).

## 설정 심화

### 이력서 첨부

**[⚙ 설정]** → **면접 설정** → **이력서** 섹션에서 파일을 추가하면 AI가 이력서를 참고하여 질문합니다.
PDF, TXT, HTML 등 다양한 형식을 지원합니다.

### 프리셋

자주 사용하는 프롬프트 + 이력서 조합을 이름으로 저장해두고 빠르게 불러올 수 있습니다.
**[⚙ 설정]** → **프리셋** 섹션에서 저장·불러오기·삭제가 가능합니다.

### STT 모델 선택

**[⚙ 설정]** → **면접 설정** → **STT 모델**

| 모델 | 크기 | 특징 |
|------|------|------|
| tiny | ~75MB | 매우 빠름, 정확도 낮음 |
| base | ~145MB | 기본값, 속도·정확도 균형 |
| small | ~465MB | 정확도 향상 |
| medium | ~1.5GB | 높은 정확도 |
| large-v3 | ~3GB | 최고 정확도, 느림 |

모델은 처음 선택 시 자동 다운로드됩니다.

### 최대 녹음 시간

기본값 120초. 0으로 설정하면 무제한.
긴 답변을 자주 한다면 늘려두는 것을 권장합니다.

## 시스템 프롬프트 작성 팁

프롬프트에 아래 항목을 포함하면 더 유효한 면접 경험을 얻을 수 있습니다.

- **지원 직군**: 예) "게임 클라이언트 프로그래머"
- **지원 회사 특성**: 예) "AAA 콘솔 게임 개발사"
- **면접 난이도**: 예) "신입 지원자 기준"
- **중점 영역**: 예) "C++, 렌더링 파이프라인, 자료구조 위주"
- **면접 분위기**: 예) "압박 면접 스타일"

예시:
```
당신은 AAA 콘솔 게임 개발사의 클라이언트 프로그래머 채용 면접관입니다.
지원자는 C++17, Unreal Engine 5, DirectX 12 경험이 있는 신입 지원자입니다.
렌더링 최적화, 메모리 관리, 멀티스레딩 역량을 중점적으로 평가해주세요.
```
